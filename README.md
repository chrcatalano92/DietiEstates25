# DietiEstates25 — Enterprise Real Estate Platform

**Software Engineering Project @ University of Naples Federico II (DIETI)**

A modular, cloud-ready real estate management platform designed and implemented following rigorous software engineering practices, formal requirements specification, object-oriented design, and automated verification.

---

### Architectural Highlights & Tech Stack

* **Core Language & Build System:** `Java` (99.8% codebase) managed via `Gradle` (`build.gradle.kts`).
* **Software Engineering Principles:** Layered architecture with clean separation of concerns, **SOLID** principles, **GoF Design Patterns**, and formal **UML** modeling.
* **Cloud & Persistence:** Deployed and tested on **Amazon Web Services (AWS)** with relational database persistence (`PostgreSQL`) and spatial/multi-criteria property filtering.
* **Security & Access Control:** Role-Based Access Control (**RBAC**) distinguishing buyers, real estate agents, and platform administrators.
